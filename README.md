# 🛠️ DIY Circular Knitting Machine Masterclass

An interactive, kid-friendly blueprint and interactive animation model for building a DIY circular knitting machine using accessible materials (UPVC pipe, wooden base, and latch needles—no 3D printing required!).

Designed and built by **TahmAdim** (*Tanvir Rahman Fahim*).

---

## 🌟 Key Features

* **Kid-Friendly Instructions**: Clear, step-by-step procedures with visual badges, numbered task bullets, and helpful "Pro Tips".
* **Interactive Canvas Animations**: Real-time vector-based HTML5 canvas diagrams detailing component assembly and sine-wave track geometry.
* **Kinematic Simulation Rig**: An interactive 60 FPS animation demonstrating how latch needles glide along the wavy cam track to catch yarn and form knitted fabric.
* **Modern UI Layout**: Fully responsive, high-contrast dark mode design built with isolated CSS Grid and Flexbox viewports to eliminate overlay clipping.
